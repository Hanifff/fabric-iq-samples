# Contributing

This is workshop material, so it is not looking for feature work. Two kinds of
contribution are welcome:

- **Corrections.** If something here is factually wrong about Microsoft Fabric
  or Fabric IQ, please say so.
- **Clarity.** If a lab step is confusing, that is a bug.

Open an issue before a pull request, so nobody spends an evening on something
that was never going to be merged.

## Licence of contributions

By contributing you agree that your contribution is licensed under the same

## Conduct

Be decent. Disagree about the technology as much as you like, and not about the
person.
